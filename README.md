# Outpace Academy landing page

Single-page Next.js site for the Outpace Chess Growth Mentorship Program.

```bash
npm install
npm run dev
```

All copy is in `src/content.ts`. Anything in `[square brackets]` is still to be
supplied. Before going live: set `whatsappNumber`, replace the sample
`sessionSlots`, and connect the form in `src/components/Site.tsx` to wherever
leads should go (it does not send them anywhere yet).
