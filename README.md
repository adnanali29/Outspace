# Outpace Academy landing page

Single-page Next.js site for Outpace Academy's chess classes.

```bash
npm install
npm run dev
```

All copy is in `src/content.ts`. Colours are in `src/app/globals.css`.

Before going live: set `whatsappNumber`, replace the sample `sessionSlots`, and
connect the form in `src/components/Site.tsx` to wherever leads should go (it
does not send them anywhere yet).
